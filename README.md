# UlTimetable Android App

<p align="center">
  <img src=".github/logo.png" alt="ultimetable-android-app logo" width="128" />
</p>

An Android app that shows University of Limerick student timetables.

## What it does

It downloads a student's timetable from the UL timetable site and shows it as
pages you can swipe between, with lectures, tutorials, labs and free slots.

## Tech

- Java for Android

## Building

This is an Eclipse Android project. Import it into Eclipse with the Android
Developer Tools, or build it with the Android SDK.
